## Assumptions

1. Synaptic events = presynaptic spikes x fan-out for every linear layer whose input is binary: the first layer
   (spike encoding), the second layer (LIF spikes) and the readout (LIF spikes). Each costs 23.6 pJ (Loihi minimum).
2. Every LIF neuron is updated every time step at 81 pJ (leak changes state every step). Readouts are non-spiking
   integrator compartments: 13 classes x T x 3 branches updates at 81 pJ.
3. Each emitted spike (input and hidden) pays one within-tile spike (1.7 pJ). Tile hops, barrier sync, static/leakage
   power, chip I/O and host-chip transfers are ignored.
4. LayerNorm between each linear layer and its LIF neuron has no Loihi equivalent. It is charged to a 45 nm FP32 host at
   4 MAC-equivalents per element. In practice it would force a host round trip every time step, which is not costed.
5. Fusion meta-network (39 -> 64 -> 13) and the softmax-weighted branch sum: dense host MACs at 4.6 pJ.
6. Spike encoding and preprocessing are excluded for every model.
7. ANN / Enc-ANN: 45 nm FP32 MAC 4.6 pJ, AC 0.9 pJ, LayerNorm 4 MAC-eq per element; GELU, control and memory excluded.
   Because Loihi's 23.6 pJ includes the synapse memory read and the 4.6 pJ MAC does not, a variant adds one 32 KB SRAM read
   (10 pJ per FP32 weight) per MAC. Loihi weights are at most 9 bit, so the INT8 figure is the like-for-like arithmetic
   comparison; it makes the gap larger, not smaller.
8. Mixing a 14 nm chip (Loihi) with 45 nm arithmetic constants is a cross-node comparison; it favours Loihi.

## LaTeX-ready paragraph (165 words)

```latex
Table~\ref{tab:loihi} replaces the arithmetic-only figures with an estimate for neuromorphic hardware. We charge each synaptic event (a presynaptic spike times its fan-out) 23.6\,pJ and each neuron update 81\,pJ, the minimum synaptic-operation and active neuron-update energies reported for Intel's Loihi chip~\cite{davies2018loihi}. Layer normalisation and the fusion network have no native Loihi counterpart and are charged to a 45\,nm host at 4.6\,pJ per MAC~\cite{horowitz2014}. Under these assumptions the E-SNN needs about 3.0, 5.9 and 8.8\,$\mu$J per flow at $T = 4$, 8 and 12, against 0.40\,$\mu$J for the matched ANN on a 45\,nm accelerator, or 1.2\,$\mu$J if every weight is also read from on-chip SRAM. Synaptic events make up more than 90\% of the E-SNN total, and about three quarters of them come from the binary input encoding. The ANN is therefore cheaper by a factor of 2.4 to 22. This is an estimate built from published per-operation figures, not a measurement, and it ignores static power, routing between cores and the cost of generating the input spikes.
```
